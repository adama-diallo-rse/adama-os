# Parcours publics ADAMA OS 2026

## Principe

Le visiteur choisit une intention, pas une branche interne.

## Entrée 1 : explorer les travaux

Public : lecteur, pair, chercheur, recruteur ou partenaire.

Promesse : accéder aux décisions, expériences, erreurs corrigées et sources datées.

Chemin : accueil -> Travaux -> preuve détaillée -> SIGNAL.

Mesure : consultation d'un travail, ouverture d'une source, inscription à SIGNAL.

## Entrée 2 : construire un système

Public : responsable data, architecte, éditeur, fondateur, consultant technique ou équipe produit ESG.

Promesse : utiliser une méthode gratuite pour passer d'une idée à un actif vérifiable.

Chemin : accueil -> Méthode -> actif gratuit -> travail lié -> SIGNAL.

Mesure : lecture complète, téléchargement futur, retour qualifié.

## Entrée 3 : résoudre un problème

Public : dirigeant ou responsable confronté à un problème de données, de règles, de preuve ou d'architecture.

Promesse : clarifier le système avant d'investir davantage.

Chemin : accueil -> Revue d'architecture -> description du problème -> échange.

Mesure : demande qualifiée, pertinence du besoin, délai de réponse.

## Boucle de conversion

Lecteur -> contact -> lecteur régulier -> utilisateur d'un actif -> acheteur d'une revue -> client logiciel éventuel de STRATA ESG.

ADAMA OS ne pousse pas directement vers une vente logicielle. Le passage vers STRATA ESG a lieu uniquement quand le besoin exige un produit opérationnel.

## Règles d'interface

- un écran, une décision principale
- un intitulé orienté résultat, jamais un nom interne seul
- une preuve visible avant un formulaire
- un formulaire court et contextualisé
- un retour explicite après chaque action
- aucune impasse, chaque page propose une suite cohérente

## Tableau de mesure initial

| Étape    | Événement                                | Indicateur                       |
| -------- | ---------------------------------------- | -------------------------------- |
| Choix    | clic OPEN, FORGE ou CONSEIL              | répartition des intentions       |
| Preuve   | ouverture d'une décision ou d'une source | taux de profondeur               |
| Relation | inscription SIGNAL                       | conversion visiteur vers contact |
| Usage    | ouverture de la méthode                  | intérêt pour les actifs          |
| Demande  | clic vers la revue d'architecture        | intention commerciale            |

Les objectifs chiffrés seront fixés après quatre semaines de données stables.
